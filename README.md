The code for my master's project which is a deep dive into the circumstellar disk around AT Pyx, a disk located within a cometary globule.

Includes algorithms for deprojecting (creating pseudo-top-down 2d views of inclined disks), calculating local FUV radiation field strength, relating characteristics of disk morphology to simulation results for inferring the presence of embedded planets, and much more!
